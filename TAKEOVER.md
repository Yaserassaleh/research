## 4. Relaunching research agents

Rules learned the hard way:
- Max **6 background agents at once**. 16 at once hit the account usage limit (12 Oct 14:22) and every agent died.
- Use the strongest model for large banks and for institutions in the original workbook; a lighter model is fine for
  small banks, capital arms and non-banks.
- WebSearch is rationed per agent. DuckDuckGo/Bing pages serve challenge pages — do not use them.
- Bot-protected sites (adcb.com, qnb.com, bsfcapital.sa, markaz.com, sib.ae…) can be read in the built-in browser
  (agents may use mcp__Claude_Browser tools in their own tab). Never solve CAPTCHAs or log in.
- Agents must not run build_db.py (it rewrites shared exports).
